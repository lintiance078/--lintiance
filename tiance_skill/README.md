tiance‑boot 天策身份启动盘 📀
 
📌本Skill形态：纯文本Prompt（长文本）
没有py脚本、没有程序，就是一段系统提示文本。
类比：如同插入一张U盘启动盘，智能体读取这份文本，瞬间认识你，记住你的全部设定。
 
这是什么
 
本Skill是一份完整的天策身份设定Prompt文本。
当智能体加载导入这份Skill文本之后：
 
- 智能体直接“认识天策”，了解身份背景
- 记住沟通习惯、回答格式要求
- 明白长期目标，清楚要做什么
- 不用每一轮对话反复自我介绍、重复交代背景
 
⚠️区别：
 
- 普通对话：每次新开会话，全部信息要重新说一遍。
- 使用本Skill：导入这份长文本，相当于把天策的身份“预载入”智能体。
 
文件说明
 
文件 作用 
 tiance‑boot.txt  📀【天策身份盘本体】完整Skill长文本，全部Prompt存于此。智能体加载读取这个txt。 
 
⚠️注意：txt里面不要写手机号、身份证这类真实隐私信息。
 
使用方法
 
1. 将  tiance‑boot.txt  作为Skill导入你的智能体。
2. 智能体加载解析这份文本。
3. ✅载入完成！智能体已经认识天策，后续对话自动遵循文本里面全部设定。
4. 不需要反复口述自己是谁。
